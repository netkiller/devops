# ExcelDiff

Excel 文件对比工具，用于比较两个 Excel 文件的内容差异。

## 安装依赖

```bash
pip3 install pandas openpyxl
```

## 命令行选项

| 选项 | 说明 |
|------|------|
| `-f` | 对比所有工作表 |
| `-s Sheet` | 指定要对比的工作表名称 |
| `-d` | 调试模式 |

## 使用方法

### 基本语法

```bash
exceldiff [options] <file1.xlsx> <file2.xlsx>
```

### 显示文件 MD5

```bash
exceldiff file1.xlsx file2.xlsx
```

会先显示两个文件的 MD5 值，如果 MD5 相同说明文件完全相同。

### 对比所有工作表

```bash
exceldiff -f file1.xlsx file2.xlsx
```

对比两个文件中的所有工作表，逐一显示每个工作表的差异。

### 对比指定工作表

```bash
exceldiff -s Sheet1 file1.xlsx file2.xlsx
```

仅对比指定名称的工作表。

## 输出示例

```

```

## 差异显示格式

差异行以以下格式显示：

```
行号1 内容1    |    行号1 内容2    # 差异行，左侧来自文件1，右侧来自文件2
行号2 内容1    <    行号2 内容2    # 左侧缺少的行
行号3 内容3    >    行号3 内容4    # 右侧缺少的行
```

无差异的行不会显示。

## 工作原理

1. 计算并显示两个 Excel 文件的 MD5 值
2. 使用 pandas 读取 Excel 文件内容
3. 将指定工作表转换为 CSV 格式保存到临时文件
4. 使用 `sdiff` 命令对比两个 CSV 文件

## 注意事项

- 需要两个文件名作为位置参数
- 支持 `.xlsx` 格式
- 第一列作为索引列（index_col=0）
- 仅支持 macOS 和 Linux 系统
- 临时 CSV 文件保存在 `/tmp/` 目录

## 适用场景

- 对比配置变更前后 Excel 表格的差异
- 检查数据导入导出是否一致
- 核对两个版本的报表差异
